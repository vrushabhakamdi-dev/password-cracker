# 🔐 Password Cracking Simulator

**CODE WITH VRUSHABH — Educational / Local Simulation Only**

A Python-based educational project that demonstrates, in a restricted local environment, the basic concept of password guessing through a small simulation.

> ⚠️ This project is intended strictly for educational and cybersecurity awareness purposes.

## ✨ Features

* 🔐 Password strength analysis
* 🔤 Limited demo character set
* 📊 Password security scoring
* 🔢 Displays the number of attempts
* ⚡ Displays guessing speed
* ⏱️ Displays elapsed time
* 🧪 Strict attempt limit
* 🛡️ Maximum password length restriction
* 💻 Simple terminal interface

## 🛠️ Requirements

* Python 3.x

No external libraries are required.

The project uses only built-in Python modules:

* `itertools`
* `string`
* `time`

## 📥 Download

Download the project files from this repository and save them to a folder on your computer.

## 🚀 How to Run

Open Command Prompt and navigate to the folder containing the Python file.

Run:

```cmd
python passwordcracker.py
```

## 🧪 Demo Restrictions

For safety and educational purposes, the simulation is intentionally restricted:

* Character set: lowercase letters (`a-z`) and numbers (`0-9`)
* Maximum password length: 6 characters
* Maximum attempts: 20,000,000
* Local simulation only

Recommended demo examples:

```text
a1
ab1
test1
```

## 📊 How It Works

The program demonstrates password security concepts using a limited local simulation.

During the demonstration, it displays:

* Current number of attempts
* Processing speed
* Current simulation value
* Total elapsed time

The program automatically stops when the configured safety limit is reached.

## 🔐 Password Security Awareness

Longer passwords and greater character variety create a significantly larger theoretical search space.

Using a combination of:

* Lowercase letters
* Uppercase letters
* Numbers
* Special characters

can significantly increase password complexity.
